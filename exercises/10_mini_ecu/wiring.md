# Lab 10: signal map

Actuator is PD12 LED only. Sensor validity is synthetic; temperature telemetry is fixed 25000 mC. CAN hub and UART4.

Renode needs no physical wires. Use the generated student launcher so the same board model, CAN connections and button overlay as the reference are loaded.

These are firmware-assigned MCU signals, not verified connector/header positions. See [the shared signal and hardware-scope notes](../WIRING.md). Physical-board validation is separate and has not been performed for these starters.
